## Descrição do projeto

<p align="justify">O projeto trata-se de um programa desenvolvido como um exercício da disciplina de Animação Computadorizada, no qual se utilizou diferentes emissores, atributos, comportamentos e critérios de morte para compor distintos sistemas de partículas. É importante observar que cada um dos sistemas de partículas possui um comportamento único.</p>

## Estrutura do projeto

<div align="center">

|sistemas_de_particulas.gd|Lê as entradas do teclado e mostra os sistemas de partículas juntos de suas respectivas informações na tela.|
